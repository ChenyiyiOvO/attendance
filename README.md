# 考勤打卡记录爬取工具

自动爬取考勤系统打卡记录，计算加班时长百分比。

## 功能

- 自动登录考勤系统爬取打卡记录
- 支持增量爬取（只爬取缺失日期）
- 自动识别周末调休工作日与法定节假日
- 计算加班时长百分比
- 自动计算本季度剩余工作日并填入第二步计算器（按 1-3/4-6/7-9/10-12 月划分季度）
- 生成CSV打卡记录文件

## 环境要求

- Python 3.10+
- 系统已安装 Edge 或 Chrome 浏览器

### 配置说明

| 字段 | 说明 |
|------|------|
| 工号 | 登录账号 |
| 密码 | 登录密码 |
| 起始日期 | 查询开始日期 (YYYY-MM-DD) |
| 终止日期 | 查询结束日期 (YYYY-MM-DD) |
| 加班起算时间 | 正常下班时间 (默认17:20) |
| 未打卡工作日天数 | 居家办公等未打卡天数 |

## 加班计算规则

- **工作日（含周末调休上班日）**：加班 = 下班打卡时间 - 17:20
- **周末、法定节假日**：当天有打卡即全天计加班 = 下班打卡时间 - 上班打卡时间
- **工作日只打了上班卡**：视为17:20准时下班，无加班（计入加班基数天数）
- **季度剩余工作日**：爬取截止日（不含）到本季度末的工作日天数，调休上班日计入、法定节假日剔除，自动填入第二步计算器的 y（可手动修改）

## 节假日数据

调休上班日与法定节假日数据来自 [holiday-cn](https://github.com/NateScarlet/holiday-cn)（按国务院公告自动更新）：

- 查询涉及的年份缺失数据时，自动联网按年拉取一次，缓存到程序目录 `holidays.json`
- 之后再运行全部走本地缓存，无网络开销
- 2024-2026年数据已内置到程序中，离线也能正确计算
- 既无缓存又无法联网的年份，退化为按周一~周五近似判断
